隐私政策

你的工作资料，保存在自己的设备上。

BobNote 的设计以本地工作为基础。本页说明具体的数据处理方式，也说明哪些操作会向外部服务发送请求。

生效日期：2026年10月21日

你的笔记

BobNote 将工作资料库保存在设备上由应用管理的本地存储中。设置 → BobFolder 存储显示大小与路径。创建 BobFolder 可将便携副本保存到你选择的位置。应用不会向 BobNote 服务上传笔记内容。我们不运营账户系统、同步服务或笔记存储服务器。

如果你把导出的 BobFolder 保存或复制到 iCloud Drive、Dropbox、OneDrive 或备份软件管理的位置，该服务会按其自身条款传输文件。是否使用这些服务由你决定。

应用

BobNote 不向我们发送使用分析、遥测或崩溃报告。应用不含广告或第三方跟踪代码。

购买由提供 BobNote 的商店处理。Mac 和 iPad 的权益验证与恢复通过 Apple 的 App Store 服务进行；Windows 的安装、许可和更新由 Microsoft Store 及 Windows 处理。这些交互受对应公司的隐私政策约束。我们只接收商店向开发者提供的报告，例如汇总销售和崩溃报告，不会收到你的支付详情。

Mac 应用每天向本网站请求一个说明当前版本的小文件，以提醒更新。该请求与访问本站一样经过 Cloudflare，处理方式如下。请求不包含账户、笔记内容，也不包含普通网页请求之外的个人信息。

部分请求仅在你主动操作时发生。播放 YouTube 卡片会从 YouTube 加载视频，Google 将按其隐私政策获取你的地址及所播放的视频。播放链接到音视频文件的卡片会从托管网站加载文件，该网站按自身条款处理你的地址和请求。未点击播放前不会加载这些媒体。打开链接时会交给浏览器，应用本身不为此发起请求。

Windows 版本

Windows 版通过 Microsoft Store 销售。购买、安装和更新由 Microsoft Store 及 Windows 按 Microsoft 隐私政策处理。可选的高级版升级、恢复购买和许可验证也使用 Microsoft Store 服务。BobNote 不接收支付详情，也不会在这些检查中发送笔记内容。

工作资料库、设置和诊断日志保存在你的电脑上。可在设置 → BobFolder 存储查看位置。清空本地存储或卸载前，请保留重要项目的独立副本，不要假设卸载会保留应用管理的数据。

查看本地画板、笔记、图片和文件不会上传其内容。许可验证可能连接 Microsoft Store 服务。Windows 版不自行检查更新，更新由 Microsoft Store 提供；前述每日版本检查仅针对 Mac 应用。

无需单独的 BobNote 账户。Microsoft Store 购买使用你的 Microsoft 账户。

播放 YouTube 或在线音视频链接时，会按前述方式从对应服务加载媒体。打开链接会交给默认浏览器。

本网站

本站不从其他来源加载资源：没有分析工具、广告、跟踪像素、外部字体或脚本，也不设置广告或分析 Cookie。

网站由 Cloudflare 提供服务。为传送网页并防御攻击，Cloudflare 在技术上需要处理请求，包括 IP 地址、所请求页面和浏览器用户代理信息。遇到可疑访问的安全验证时，可能设置必要的安全 Cookie。我们不接收、存储或分析这些信息。

邮件与诊断报告

诊断可把错误报告作为 PDF 保存在你的设备上，不会自动发送给我们。如果选择发送，请先检查内容：诊断信息可能包含本地路径及相关操作详情。涉及个人信息时，请使用私下支持渠道。

向support@bobnote.app发送邮件后，我们会收到你的邮箱地址、正文和附件，仅用于回复你的问题。支持往来保留24个月，随后删除。

通过 Telegram 联系我们

Telegram 会按其自身隐私政策接收和保存消息。我们可以看到你的 Telegram 用户名、显示名称和发送的内容。

BobNote 用户群是公开的，任何人都可能找到并阅读。你的 Telegram 用户名和发言会对群成员及查看者可见。

我们不控制 Telegram，也无法删除 Telegram 所保存的数据。如果需要私下支持渠道，请使用电子邮件。

使用 BobNote 不要求加入或联系 Telegram，两个 Telegram 渠道都不会向应用发送数据。

你的权利

你可以询问我们持有哪些个人数据，并要求更正或删除。请联系support@bobnote.app，我们会在30天内回复。通常我们可能持有或看到的个人数据，仅为你发来的支持邮件或前述 Telegram 信息。

Mac 与 iPad 的交易由 Apple 处理，Windows 的交易由 Microsoft 处理。相关交易信息由对应商店持有，请向相应商店提出请求。

儿童

BobNote 并非面向儿童设计。应用不收集任何用户的个人数据，包括儿童。

政策更新
