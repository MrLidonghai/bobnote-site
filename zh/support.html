常见问题

你可能想了解的事

BobNote 支持简体中文吗？

在设置中选择跟随系统、English 或简体中文，重新打开 BobNote 后生效。笔记原文、画板名称和文件名保持不变。本网站的语言切换只改变网页语言，不会改变已安装应用的语言或功能。

什么是 BobFolder？

便携 BobFolder 将一个画板、它的嵌套画板和所含文件保存在一起。用创建 BobFolder 创建独立副本，再通过云盘、USB 或其他可信方式传输完整文件夹。在目标设备上，合并导入 BobFolder 会将副本加入当前画板，不替换已有工作。这是主动交接，不是自动同步。

我的文件放在哪里？

工作资料库保存在设备上的 BobNote 本地存储中。打开设置 → BobFolder 存储可查看大小和完整路径。需要将便携副本放到自选位置时，使用创建 BobFolder。BobNote 不会把你的笔记上传到 BobNote 服务器。

如何备份笔记？

请保留设备备份及重要项目的独立副本。使用高级版时，打开项目画板并执行创建 BobFolder，再把整个导出文件夹保存到另一块硬盘或自选备份服务。从首页开始可包含其画板树。便携副本保存导出的项目，但不等同于所有应用设置、撤销记录和收集篮内容的完整备份。

离开 BobNote 后，资料还能使用吗？

可将画板导出为 PDF 供阅读和分享。便携 BobFolder 将所含文件与画板数据保存在一起；这些文件可由兼容应用打开，可编辑画布及其关系由 BobNote 读取。清空本地存储或卸载应用前，请保留独立副本。

标准版与高级版

购买应用即包含标准版。高级版是可选的一次性升级，无需订阅。

选择适合你的功能
功能标准版高级版
日常卡片、本机保存与演示包含包含
完整思维导图包含包含
PDF 导出带 BobNote 标识不带 BobNote 标识
创建／合并导入 BobFolder不包含包含

Mac 与 iPad 共享同一 Apple 账户的应用购买和高级版权益。Windows 需通过 Microsoft Store 单独购买；Apple 与 Microsoft 的购买不可互换。

为什么 PDF 上有标识？

标准版即可导出 PDF，但页面角落会带有 BobNote 标识。标识只出现在导出的 PDF 中，不会修改笔记或 BobFolder 内的原文件。解锁高级版后，同一画板可导出不带标识的 PDF。

购买遇到问题，该联系谁？

请联系购买所用的商店。Mac 和 iPad 的收据及退款由 Apple 的 App Store 账户设置管理；Windows 则由 Microsoft 账户的订单记录管理。

需要账户或网络吗？

使用 BobNote 本身无需创建 BobNote 账户，已保存的本地资料可离线使用。购买、安装、更新、恢复购买或验证许可需要使用 App Store 或 Microsoft Store 账户，并可能需要联网。离线前请下载所需文件。播放 YouTube 或卡片中的在线音视频链接也需要网络。

发现问题，或想提出建议？

请告诉我们你在做什么、预期结果以及实际发生的情况。遇到错误时，打开设置 → 诊断 → 保存错误报告为 PDF。先检查保存的报告，再附上简要说明，通过以下入口联系我们：联系支持。报告不会自动发送。包含个人信息时，请使用邮件或私信，不要发到公开群组。也欢迎提出功能建议。
