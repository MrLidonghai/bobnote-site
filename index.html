Start with the material

Bring photos, documents, links and notes into a Project Board. Arrange related material together, with nested Boards for the details. Open external files in a compatible app when needed.

Refine it on the same canvas

Compare options, select what matters, annotate details and write your conclusions beside the sources. Your collection, thinking and useful outcomes can stay in one project.

Present it. Pass it on.

Walk through the canvas in a meeting, or make a focused Board for your audience. Export a PDF for viewing, or create a BobFolder so someone can import your selected project into BobNote, continue working and return an updated copy.

Local by design.

Your working library stays on your device. Saved notes and local files work offline. No BobNote account is needed.

Choose what travels.

Create a BobFolder from a selected Board, with its nested Boards and included files. Transfer the complete folder by USB, Wi-Fi file transfer or your chosen cloud drive. The recipient uses Combine a BobFolder to import it. This is a handoff between copies, not live sync or automatic merging.
