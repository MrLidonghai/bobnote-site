# bobnote.sg

The official website for BobNote — local-first visual notes for the Mac.

Plain HTML and CSS, served as-is. No JavaScript, no web fonts, no analytics,
no cookies, and no requests to any third-party server. The site makes a promise
about privacy, and the simplest way to keep it is to have nothing here that
could break it.
